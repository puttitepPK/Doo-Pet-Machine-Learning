## ถ้าต้องการใช้งานหน้าเว็บ

เปิด API เหมือนเดิม จากโฟลเดอร์โปรเจกต์:

```powershell
cd model
python main.py
```

เปิดอีก Terminal จากโฟลเดอร์โปรเจกต์ แล้วรัน `npm run dev` ไม่ต้องรันไฟล์ Python ภายใน `b3` ทีละไฟล์ และไม่ต้องเปิด Colab เพื่อใช้โมเดลที่ฝึกแล้ว

หน้าเว็บมีเพียงการอัปโหลดรูปและดูผล ผู้ใช้ไม่ต้องเลือกโหมด TTA

### ตั้งค่า TTA ในโค้ด

แก้ตัวแปร `B3_TTA_OVERRIDE` ด้านบนของ [`b3_inference.py`](b3_inference.py) แล้วรีสตาร์ต API:

| ค่า | วิธีทำนาย B3 บนเว็บ |
|---|---|
| `True` | เปิด TTA 6 แบบตาม B0 แล้วเฉลี่ยคะแนนของแต่ละกลุ่ม |
| `False` | ปิด TTA: ใช้ภาพเดียว |

ปัจจุบันคงค่าที่ผู้ใช้ตั้งไว้ `B3_TTA_OVERRIDE = True` จึงเปิด TTA 6 แบบ โหมดบนเว็บกำหนดจากตัวแปรนี้โดยตรง ทั้งสองวิธีใช้ `.pth` ไฟล์เดียวกัน หากต้องการเปรียบเทียบระหว่างพัฒนา ยังใช้ `b3_tta=true/false` ผ่านหน้า API `/docs` ได้

### TTA 6 แบบทำงานอย่างไร

`build_b3_views()` สร้างภาพก่อนปรับขนาด ด้วยขั้นตอนเดียวกับ B0 เดิม:

| แบบ | สิ่งที่ทำ |
|---|---|
| ต้นฉบับ | เก็บรูปเดิม |
| ปรับแสง | Autocontrast cutoff 1 ชดเชยภาพมืด/สว่าง และปรับ Sharpness 1.5 |
| ครอป | ตัดขอบภาพปรับแสงออกด้านละ 12% เมื่อภาพใหญ่กว่า 64 พิกเซลทั้งสองด้าน |
| เพิ่มความคม | ฟิลเตอร์ SHARPEN บนภาพปรับแสง |
| เพิ่มความสว่าง/คอนทราสต์ | คูณความสว่าง 1.2 และคอนทราสต์ 1.2 บนภาพปรับแสง |
| กลับซ้าย–ขวา | พลิกภาพปรับแสงในแนวนอน |

`build_b3_batch()` นำแต่ละภาพผ่าน Resize ด้านสั้น 320 → Center crop 300×300 → Tensor → Normalize ตาม B3 เดิม แล้ว `main.py` ทำนายและเฉลี่ย Softmax ของทั้ง 6 ภาพ ไม่เลือกเฉพาะภาพที่ได้คะแนนสูงสุดและไม่ฝึกน้ำหนักใหม่

ทั้ง 6 แบบแปลงจากรูปเดียว ไม่ใช่การเห็นผิวหนังด้านที่ไม่ได้ถ่ายมา การครอปอาจตัดรอยโรคและการปรับแสงอาจเปลี่ยนสีสำคัญ จึงยังต้องวัดผลก่อนสรุปว่าแม่นขึ้น

### รัน Colab โดยไม่ฝึกใหม่

รายงานจัดตามไฟล์ Checklist ที่ผู้ใช้ให้มา เริ่มจาก **1 → 2 → 14.1 → 14.2 → 14.3 → 15.1 → 15.2** ได้ใน Runtime ใหม่ ไม่ต้องฝึกขั้น 12–13 ซ้ำ:

- **14.1**: ประวัติ Train ของรอบที่เลือก จำนวนรอบจริงเทียบแผน และกราฟ Train/Validation พร้อมเส้นรอบที่เลือก
- **14.2**: Validation ภาพเดียวเท่านั้น มี Loss/Accuracy/Precision (Macro)/Recall (Macro)/Macro F1 รายงาน 6 กลุ่ม กราฟ และ Confusion Matrix ของภาพเดียว
- **14.3**: Validation TTA 6 แบบ มีตารางและกราฟชุดเดียวกันสำหรับ TTA โดยเฉพาะ พร้อมตารางเปรียบเทียบกับภาพเดียวท้ายช่อง
- **15.1**: ผล Test ภาพเดียวที่บันทึกไว้ รวม Loss ที่คำนวณเพิ่มจากคะแนนเดิม
- **15.2**: Test ของโหมดที่กำหนด พร้อมรายงาน/กราฟ และตาราง Train/Validation/Test ในที่เดียว
- **16**: ตั้ง `USE_TTA_FOR_UPLOAD = True/False` เพื่อลองรูปเดียวกัน ตั้ง `SHOW_TTA_VIEWS = True` เพื่อดูภาพที่สร้างครบ 6 แบบ
- **17**: ตรวจโหลด `.pth` กลับและรวมรายงานส่งออก

ตั้ง `REPORT_USE_TTA = True/False` ใน 14.3 ให้ตรงกับ `B3_TTA_OVERRIDE` บนเว็บ ตัวแปรนี้เลือกโหมด Test 15.2 และสรุปรวมเท่านั้น: 14.2 ยังคงเป็นภาพเดียว และ 14.3 ยังคงเป็น TTA เสมอ ไม่เลือกโหมดจากคะแนน Test รายงานแสดงทุกคะแนนเป็นเปอร์เซ็นต์ ยกเว้น Loss และ Support; แสดงค่าเฉลี่ย Macro แยกจากตาราง 6 กลุ่มเพื่อลดความสับสน

Loss ของ Validation/Test คำนวณ NLL จากคะแนนของคำตอบจริง และใช้ class weights เดียวกับตอนฝึกถ้ามี ค่า Train มาจากประวัติการฝึกที่มี Augmentation และน้ำหนักเปลี่ยนระหว่างรอบ จึงระบุแหล่งค่าไว้ชัดเจนในตาราง หากคะแนนคำตอบจริงเป็นศูนย์จะจำกัดค่าก่อน log และแจ้งจำนวนภาพที่ได้รับผลกระทบ

รายงานอ่านง่ายอยู่ใน Run เดิมใต้ `reports/readable_v1_<รหัสน้ำหนัก>/` มี CSV/JSON และ PNG รวมใน ZIP ขั้น 17 ส่วนคะแนน TTA/cache ยังอยู่ใต้ `tta_validation/six_view_v1_<รหัสน้ำหนัก>/` แคช `hflip_v1` ไม่ถูกใช้แทนแบบ 6 ภาพ ไฟล์ฝึกและผล baseline เดิมยังอยู่
